Client-Server Decoupling

The web application uses asynchronous AJAX (Fetch API) requests between the client browser and the Flask REST server. This prevents full-page reloads and provides a smooth progress indicator while PyTorch executes neural network inference.

Security & Memory Management

Uploaded DICOM images are sanitized using secure_filename and assigned unique UUIDs. Temporary uploaded image files are processed statelessly in isolated directories to guarantee patient data privacy and efficient memory disposal.
