Data Preprocessing Stage

When a medical image file (DICOM `.dcm`, `.ima`, or `.png`) is uploaded, the Flask backend converts raw pixel intensity matrices into standardized floating-point arrays.

img = img - img.min()
img = img / (img.max() + 1e-8) # Scale to [0, 1]
Resized to 256x256 tensor representation with dimensions (1, 1, 256, 256) matching U-Net input expectations.
PyTorch Model Execution

The preprocessed tensor passes through the forward pass of the U-Net neural network loaded on CPU/GPU:

with torch.no_grad():
  enhanced_tensor = model(input_tensor)
Skip connections preserve structural anatomy while the bottleneck filters out low-dose noise components.
