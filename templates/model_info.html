U-Net Architecture Overview

The U-Net architecture (Ronneberger et al.) is a convolutional neural network designed specifically for biomedical image-to-image translation tasks. Its symmetric "U" shape consists of a contracting encoder path, a bottleneck bridge, and an expanding decoder path.

1. Encoder Path

Downsamples spatial resolution while extracting high-level semantic features using Conv2D (3x3), ReLU, and MaxPool (2x2).

2. Bottleneck Bridge

Processes 512 deep feature channels, capturing global contextual representations across the PET slice.

3. Decoder Path

Upsamples feature maps using ConvTranspose2d, concatenating high-resolution skip connections from the encoder.

Layer Channel Map

Exact channel progression used in this project:

1 → 64 64 → 128 128 → 256 256 → 512 512 → 256 256 → 128 128 → 64 64 → 1
Role of Skip Connections

Skip connections copy feature maps from the encoder to the matching decoder stage via torch.cat([u, c], dim=1). This preserves organ boundaries and lesion edges that would otherwise be lost after downsampling.

Why U-Net is Optimal for PET Enhancement

Small Dataset Efficiency

U-Net achieves superior generalizability even when trained on modest medical dataset sizes by exploiting localized spatial patch context.

Precise Spatial Localization

Combines high-level context ('what') with precise spatial localization ('where'), essential for accurate metabolic lesion boundaries in nuclear medicine.
